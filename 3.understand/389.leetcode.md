# Progressive Explanation for 389. Find the Difference

## Problem Description
You are given two strings `s` and `t`. String `t` is generated by random shuffling string `s` and then adding one more letter at a random position. Return the letter that was added to `t`.

---

## Brute Force Approach

### Idea:
1. Count the frequency of each character in both `s` and `t`.
2. Compare the counts of each character.
3. The character with a count difference of 1 in `t` is the extra character.

### Code:
```python
from collections import Counter

class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        count_s = Counter(s)
        count_t = Counter(t)
        for char in count_t:
            if count_t[char] != count_s.get(char, 0):
                return char
```

### Complexity:
- **Time Complexity**: `O(n)` where `n` is the length of `s + t`.
- **Space Complexity**: `O(1)` if we assume the alphabet size is constant.

---

## Optimal Approach

### Idea:
1. Use XOR to find the extra character.
2. XOR all characters in `s` and `t`. Since XOR of two identical characters is 0, the result will be the ASCII value of the extra character.

### Code:
```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        result = 0
        for char in s + t:
            result ^= ord(char)
        return chr(result)
```

### Complexity:
- **Time Complexity**: `O(n)` where `n` is the length of `s + t`.
- **Space Complexity**: `O(1)` as we only use a single variable to store the XOR result.
