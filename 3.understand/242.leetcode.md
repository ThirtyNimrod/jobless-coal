# 242. Valid Anagram  Progressive Explanation

## Plain English Summary

> In plain English: Given two strings `s` and `t`, determine if `t` is an anagram of `s`. An anagram means both strings contain the same characters with the same frequency, but possibly in a different order.

## Example Walkthrough

### Example 1

Input: `s = "anagram"`, `t = "nagaram"`

1. Both strings have the same length (7).
2. Count the frequency of each character in `s`:
   - `a: 3, n: 1, g: 1, r: 1, m: 1`
3. Count the frequency of each character in `t`:
   - `a: 3, n: 1, g: 1, r: 1, m: 1`
4. Compare the two frequency counts. They are equal, so return `True`.

### Example 2

Input: `s = "rat"`, `t = "car"`

1. Both strings have the same length (3).
2. Count the frequency of each character in `s`:
   - `r: 1, a: 1, t: 1`
3. Count the frequency of each character in `t`:
   - `c: 1, a: 1, r: 1`
4. Compare the two frequency counts. They are not equal, so return `False`.

---

## Approach 1: Sorting

### The Idea
Sort both strings and compare them. If they are equal, the strings are anagrams.

### Visual Trace

Input: `s = "anagram"`, `t = "nagaram"`

1. Sort `s`: `['a', 'a', 'a', 'g', 'm', 'n', 'r']`
2. Sort `t`: `['a', 'a', 'a', 'g', 'm', 'n', 'r']`
3. Compare the sorted strings. They are equal, so return `True`.

### Code
```python
def isAnagram(s: str, t: str) -> bool:
    if len(s) != len(t):
        return False
    return sorted(s) == sorted(t)
```

### Complexity
- **Time:** O(n log n)  Sorting both strings
- **Space:** O(n)  Storing sorted strings

### The Flaw
Sorting is slower than necessary for large inputs. We can solve this problem in linear time using a hash map.

---

## Approach 2: Hash Map

### The Idea
Count the frequency of each character in both strings using a dictionary. Compare the two dictionaries. If they are equal, the strings are anagrams.

### Visual Trace

Input: `s = "anagram"`, `t = "nagaram"`

1. Count the frequency of each character in `s`:
   - `a: 3, n: 1, g: 1, r: 1, m: 1`
2. Count the frequency of each character in `t`:
   - `a: 3, n: 1, g: 1, r: 1, m: 1`
3. Compare the two dictionaries. They are equal, so return `True`.

### Code
```python
def isAnagram(s: str, t: str) -> bool:
    if len(s) != len(t):
        return False

    count_s, count_t = {}, {}

    for char in s:
        count_s[char] = count_s.get(char, 0) + 1

    for char in t:
        count_t[char] = count_t.get(char, 0) + 1

    return count_s == count_t
```

### Complexity
- **Time:** O(n)  Counting character frequencies
- **Space:** O(1)  Fixed size for lowercase English letters

### The Win
This approach avoids sorting and solves the problem in linear time, making it more efficient for large inputs.
