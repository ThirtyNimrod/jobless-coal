# Move Zeroes — Progressive Explanation

## Problem Statement

Given an integer array `nums`, move all `0`'s to the end of it while maintaining the relative order of the non-zero elements.

### Example:

**Input**: nums = [0,1,0,3,12]  
**Output**: [1,3,12,0,0]

---

## Brute Force Approach

### Idea:
- Create a new array.
- Iterate through the input array and add all non-zero elements to the new array.
- Add zeros to the end of the new array to match the original array's length.

### Code:
```python
from typing import List

def moveZeroes(nums: List[int]) -> None:
    result = []
    zero_count = 0

    for num in nums:
        if num != 0:
            result.append(num)
        else:
            zero_count += 1

    result.extend([0] * zero_count)
    nums[:] = result
```

### Complexity:
- **Time Complexity**: O(n) for iterating through the array and appending zeros.
- **Space Complexity**: O(n) for the new array.

---

## Optimized Approach (Two Pointers)

### Idea:
- Use two pointers: `last_non_zero` and `i`.
- `last_non_zero` keeps track of the position where the next non-zero element should be placed.
- Iterate through the array with `i`. If `nums[i]` is non-zero, swap it with `nums[last_non_zero]` and increment `last_non_zero`.

### Code:
```python
from typing import List

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        last_non_zero = 0  # Pointer to place the next non-zero element

        for i in range(len(nums)):
            if nums[i] != 0:
                nums[last_non_zero], nums[i] = nums[i], nums[last_non_zero]
                last_non_zero += 1
```

### Complexity:
- **Time Complexity**: O(n) — Single pass through the array.
- **Space Complexity**: O(1) — In-place modification.

---

## Why Two Pointers Work

- The `last_non_zero` pointer ensures that all non-zero elements are moved to the front of the array.
- The `i` pointer iterates through the array, checking each element.
- By swapping only when necessary, we minimize the number of operations.
