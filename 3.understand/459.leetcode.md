# 459. Repeated Substring Pattern  Progressive Explanation

## Plain English Summary

> In plain English: Given a string `s`, check if it can be constructed by repeating a substring of itself multiple times.

## Example Walkthrough

### Example 1

Input: `s = "abab"`

1. Concatenate `s` with itself: `"abababab"`.
2. Remove the first and last characters: `"bababa"`.
3. Check if `s` exists in the modified string: `"abab"` is in `"bababa"`, so return `True`.

### Example 2

Input: `s = "aba"`

1. Concatenate `s` with itself: `"abaaba"`.
2. Remove the first and last characters: `"baab"`.
3. Check if `s` exists in the modified string: `"aba"` is not in `"baab"`, so return `False`.

---

## Approach 1: String Manipulation

### The Idea
Concatenate the string with itself and remove the first and last characters. If the original string exists in the modified concatenated string, it can be constructed by repeating a substring.

### Visual Trace

Input: `s = "abab"`

1. Concatenate `s` with itself: `"abababab"`.
2. Remove the first and last characters: `"bababa"`.
3. Check if `s` exists in the modified string: `"abab"` is in `"bababa"`, so return `True`.

### Code
```python
def repeatedSubstringPattern(s: str) -> bool:
    doubled_s = (s + s)[1:-1]
    return s in doubled_s
```

### Complexity
- **Time:** O(n)  Checking substring in concatenated string
- **Space:** O(n)  Concatenated string

### The Flaw
This approach is efficient, but it relies on string concatenation, which uses extra space.

---

## Approach 2: Mathematical

### The Idea
Iterate through all possible substring lengths. If the length of the string is divisible by the substring length, check if repeating the substring forms the original string.

### Visual Trace

Input: `s = "abab"`

1. Try substring length `l = 1`:
   - Substring: `"a"`
   - Repeat: `"aaaa"` (not equal to `"abab"`)
2. Try substring length `l = 2`:
   - Substring: `"ab"`
   - Repeat: `"abab"` (equal to `"abab"`)
3. Return `True`.

### Code
```python
def repeatedSubstringPattern(s: str) -> bool:
    n = len(s)
    for l in range(1, n // 2 + 1):
        if n % l == 0:  # Check if length is divisible
            if s[:l] * (n // l) == s:
                return True
    return False
```

### Complexity
- **Time:** O(n)  Iterating through possible substring lengths
- **Space:** O(1)  No extra space used

### The Win
This approach avoids string concatenation and uses constant space, making it more memory-efficient.
