# Claude Progressive DSA Teaching

## Purpose
Provide comprehensive, beginner-friendly explanations that progress from brute force to optimal solutions for any DSA problem.

## Workflow
1. **Analyze the problem** - understand constraints, edge cases, examples.
2. **Brute force approach** - explain the simplest possible solution, identify inefficiencies.
3. **Optimizations** - introduce improvements incrementally, explaining trade-offs.
4. **Optimal solution** - present the best approach with full implementation.
5. **Complexity analysis** - explain time/space complexity in plain English at each step.
6. **Save documentation** - create comprehensive lesson in 3.understand/ with examples and explanations.

## Key Principles
- Never skip steps - fill all gaps for complete beginners.
- Always explain WHY, not just HOW.
- Use multiple examples to illustrate concepts.
- Reference previously solved problems.
- Show real execution traces with input/output.
- Link to related algorithms and data structures.

## Usage Examples
- "Explain the two-pointer technique from brute force to optimal"
- "Walk me through problem 28 step by step"
- "How do I solve this string matching problem?"
- "Teach me hash maps with examples from my previous problems"
