# XOR Operation

## Concept Explanation
The XOR operation is a bitwise operator that compares two bits and returns `1` if the bits are different, and `0` if they are the same. It has the following properties:

1. `a ^ a = 0` (XOR of a number with itself is 0).
2. `a ^ 0 = a` (XOR of a number with 0 is the number itself).
3. XOR is commutative and associative, meaning the order of operations does not matter.

### When to Use:
- When you need to find a unique element in a collection where all other elements appear in pairs.
- When you need to toggle bits or perform parity checks.

### Example Problem: Find the Difference (389)

#### Problem:
You are given two strings `s` and `t`. String `t` is generated by random shuffling string `s` and then adding one more letter at a random position. Return the letter that was added to `t`.

#### Solution:
We can use the XOR operation to find the extra character in `t`. By XORing all characters in `s` and `t`, all characters that appear in both strings cancel out, leaving only the extra character in `t`.

#### Code:
```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        result = 0
        for char in s + t:
            result ^= ord(char)
        return chr(result)
```

---

## Complexity:
- **Time Complexity**: `O(n)` where `n` is the length of `s + t`.
- **Space Complexity**: `O(1)` as we only use a single variable to store the XOR result.
