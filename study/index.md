# Study Index

This file summarizes the concept lessons in `study/` and links to each lesson with a short description and practice items.

- `Hash Maps` — constant-time lookups for keys; useful for counting, grouping, and mapping. See [study/hash_maps.md](study/hash_maps.md).
- `String Matching` — substring search algorithms, from brute-force to KMP. See [study/string_matching.md](study/string_matching.md).
- `Two Pointers` — in-place and paired traversal patterns for arrays/strings. See [study/two_pointers.md](study/two_pointers.md).
- `XOR Operation` — bitwise techniques for single-element and parity problems. See [study/xor_operation.md](study/xor_operation.md).

## Exercises at a glance
- Each lesson includes 1–2 short practice problems to implement and test.
