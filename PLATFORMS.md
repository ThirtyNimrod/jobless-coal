## How to Choose Your Platform

### Use Claude If:
- You want **detailed, progressive explanations**
- You prefer **deep learning** over quick coding
- You use **Claude Code or Claude Desktop**
- You need **in-depth algorithm analysis**

### Use AntiGravity If:
- You want **fast iteration and quick solutions**
- You're in a **collaborative learning environment**
- You prefer **lightweight workflows**
- You want **rapid code generation and testing**

### Use Gemini If:
- You're a **visual learner**
- You want **rich multimodal explanations**
- You need **algorithm visualizations**
- You want **interactive execution flows**

### Use GitHub Copilot If:
- You use **VS Code**
- You prefer **token-efficient caveman mode**
- You want **GitHub-integrated workflows**
- You need **fast, terse responses**

## Unified Approach

All platforms share:
- **Same directory structure** (1.questions/, 2.answers/, 3.understand/, study/)
- **Same file naming conventions**
- **Same problem database**
- **Same index system**

**Benefit:** Switch between platforms without losing your work!

## Getting Started

1. **Choose your platform** based on your workflow and learning style
2. **Read the platform-specific README** in that folder
3. **Review the instructions file** (e.g., `claude.instructions.md`)
4. **Pick an agent** that matches your task
5. **Use the associated skills** to automate documentation
